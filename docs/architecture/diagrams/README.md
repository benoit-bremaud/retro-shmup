# UML study — index

UML 2.5 diagrams in Mermaid, one folder per feature, numbered by conception stage:

```
docs/architecture/diagrams/<feature>/
  01-use-case.md
  02-sequence.md
  03-component.md
  04-class.md
  05-state.md
  06-data-flow.md
```

Conventions: use cases are actor-initiated goals grouped by domain (never by implementing
component); the component split lives in the component diagram only. Diagrams are the contract
the implementation must satisfy — no feature is coded before its diagrams are validated.
